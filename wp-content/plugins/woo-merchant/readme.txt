Enhance your WooCommerce store with advanced features like product discounts, sale countdown timers, low stock notifications, frequently bought together products, and a "Buy Now" button.

== Description ==

**Woo Merchant** supercharges your WooCommerce store by adding powerful features designed to enhance sales and improve customer experience.  

**Key Features:**  
- **Frequently Bought Together Products:** Boost average order value by showing related products frequently bought together.  
- **Product Discounts:** Enable/disable discounts by percentage or fixed value.  
- **Sale End Countdown/Timer:** Create urgency with a countdown timer for product sales.  
- **Low Stock Notifications:** Display alerts for products running low on stock to encourage quick purchases.  
- **Buy Now Button:** Simplify the purchasing process with a one-click "Buy Now" button.
- **Size Guide Image:** Enable/disable a size guide image on product pages, with an option to upload a custom size guide in product settings.  

With an intuitive backend and seamless integration with WooCommerce, Woo Merchant is the perfect plugin to grow your eCommerce business.  

== Installation ==

**From within WordPress**  
1. Visit **Plugins > Add New**.  
2. Search for **Woo Merchant**.  
3. Click the **Install Now** button to install the plugin.  
4. Click the **Activate** button to activate the plugin.  

**Manually**  
1. Unzip the download package.  
2. Upload the folder `woo-merchant` to the `/wp-content/plugins/` directory.  
3. Activate the plugin through the 'Plugins' menu in WordPress.
