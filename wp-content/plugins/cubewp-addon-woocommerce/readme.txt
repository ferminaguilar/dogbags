== Description ==

CubeWP WooCommerce seamlessly integrates WooCommerce with the CubeWP Frontend Pro plugin, enabling advanced eCommerce functionality directly from your WordPress frontend. This addon allows you to create, manage, and customize WooCommerce products, orders, and customer profiles using intuitive frontend forms and layouts.

Key Features:

- **Frontend Product Management:** Easily add, edit, and manage WooCommerce products from the frontend, including support for custom fields, product categories, tags, images, pricing, and inventory.
- **Order Handling:** View and manage WooCommerce orders through custom frontend dashboards, with options to filter, search, and update order statuses.
- **Customer Profiles:** Enable customers to view and update their WooCommerce profile information, addresses, and order history using customizable frontend forms.
- **Custom Layouts:** Build unique product and shop layouts using CubeWP’s drag-and-drop builder, ensuring your store matches your brand and design preferences.
- **Advanced Search & Filters:** Enhance product search and filtering capabilities by adding custom fields and criteria to WooCommerce product listings.
- **Role-Based Access:** Control which user roles can access specific WooCommerce features and forms on the frontend.
- **Seamless Integration:** Works with existing CubeWP and WooCommerce features, ensuring compatibility and smooth operation.

This addon is ideal for store owners who want to provide a seamless, user-friendly frontend experience for managing WooCommerce stores, products, and customers without relying on the WordPress backend.
